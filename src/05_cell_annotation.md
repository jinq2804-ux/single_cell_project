根据每个聚类的基因表达特征，判断它可能是哪种细胞类型


Marker Gene 标记基因
某些基因在特定细胞类型中具有比较典型的表达模式，因此可以帮助我们识别细胞类型
注意：不是一个基因决定一个细胞类型，而是多个基因共同提供证据

因为不同细胞类型之间可能共享部分 Marker Gene
比如：
· T 细胞和 NK 细胞都可能表达某些细胞毒性相关基因。
· 单核细胞和树突状细胞也可能共享部分髓系基因。
因此需要：
ANCHORS 能够支持该细胞身份的关键标记基因

Wilcoxon 秩和检验：是一种非参数统计检验
它不是简单比较两组平均值，而是利用观测数据的相对排序，分析两组数据的分布是否存在差异。
例如，对于某个基因：
- 一组是聚类 1 中所有细胞的表达值。
- 另一组是其他聚类中所有细胞的表达值。
Wilcoxon 检验会判断这两组表达数据是否存在统计意义上的差异。
它会为基因产生统计检验结果，包括 P 值。

P 值：
用于衡量在零假设成立的前提下，观察到当前程度或更极端统计结果的可能性。
零假设可以理解为两组表达分布没有系统性差异。
P 值较小，可以为拒绝零假设提供证据。
但是，P 值小，不等于表达差异一定很大，也不等于这个基因一定能确定细胞类型。

密集矩阵（普通数组） 和 稀疏矩阵
密集矩阵（Dense Matrix / np.array）：
长相：传统的、填满数字和大量 0 的巨型二维方格表。
优缺点：人类一眼能看懂，但会因存储大量无意义的 0 而极度消耗内存。
稀疏矩阵（Sparse Matrix）：
长相：类似“只记录非零项坐标和数值”的压缩账本（如 CSR 格式）。
优缺点：极省内存、计算高效，是单细胞数据默认的存储格式。
.toarray() 的作用
定义：将 Scanpy 内存中压缩的稀疏矩阵，“解冻”并还原为人类及普通 Pandas 表格能直接读取的密集矩阵（普通数组）。
当需要将数据转换为 Pandas DataFrame、做热图绘制或自定义统计计算时使用。
