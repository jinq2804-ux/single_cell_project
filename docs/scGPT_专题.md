# 从 Transformer 到 scGPT

## 从词元到上下文向量

LLM 是在大规模文本等数据上训练的语言模型。文本先被分割成词元（token），例如一个字、词的一部分或标点。词元 ID 是查表索引，对应的 embedding 是可训练的向量。普通 GPT 在表示中纳入位置信息，用因果掩码限制一个位置可查看哪些位置，训练时预测下一个文本词元。

在自注意力的一头中，输入矩阵 X 的每行对应一个位置。计算 Q = XWq、K = XWk、V = XWv。QKᵀ 产生两两匹配分数，除以 √dₖ 控制分数尺度。把禁止访问的分数置为负无穷，再按每行做 softmax。最后用权重矩阵乘 V，每个位置得到它从允许位置汇聚的信息。多头让各头学习不同投影，前馈网络、残差连接和归一化继续更新每个位置的表示。注意力权重可以用于观察模型行为，因果调控需要独立证据。

## 基因身份与表达量

scRNA-seq 的一个细胞可以表示为一批带表达量的基因。不同细胞有不同的表达组合，注意力可以让一个基因的表示结合该细胞中其他基因的上下文。对 scGPT 而言，基因符号先映射到模型词表中的 ID，再查表取基因向量。表达量走单独的编码支路，具体用连续值编码、分箱等方式取决于模型和检查点配置。论文和注释教程中的分箱把表达强度转换成离散等级。常见配置将基因向量与表达向量相加，并使用特殊标记汇聚细胞级向量。基因没有自然语句的阅读顺序，录入表格的列序不代表生物学先后。

普通 GPT 在语言序列上预测后继词元。scGPT 的生成式预训练利用已知表达上下文估计待预测基因的表达，用面向单细胞数据的掩码和训练目标。它们共享 Transformer 的基本计算，但输入语义、掩码和预测目标各有定义。scGPT 论文报告使用 3,300 多万个细胞做预训练。预训练是在大量细胞上先学习可迁移表示，微调是用具体任务和标签继续训练预训练参数和任务头。冻结编码器、只训练一个分类头也可作为迁移学习基线。

## 如何接回本项目

现在的 MLP 每次处理一个 765 维固定表达向量，输出 10 个类别分数。后续可在带独立供体标识的注释数据上比较「传统表达特征＋逻辑回归」「冻结 scGPT 的细胞向量＋逻辑回归」「scGPT 微调」。首先核对基因命名与检查点词表，保存词表命中率与处理配置，再用供体分组切分。比较 Macro-F1、每类召回和计算成本，尤其检查小类和批次。基础模型也可用于细胞表征、批次整合和多模态整合，适用性取决于训练数据覆盖和下游验证。

本项目没有加载 scGPT 权重、运行官方教程或训练 Transformer。项目的实验指标来自逻辑回归、随机森林和 PyTorch MLP。
